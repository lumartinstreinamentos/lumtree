Guia de Criação de
Cursos Lumtree

Tudo que sua equipe precisa saber para criar, produzir e publicar cursos EAD com o padrão Lumtree — do primeiro rascunho até o aluno acessando na Kiwify.

Sobre este guia

Por que este
documento existe

Este guia foi criado a partir do processo real de produção do curso Base da Gestão de Projetos — o primeiro curso EAD da Lumtree. Ele consolida todas as decisões pedagógicas, técnicas e editoriais que tomamos ao longo da produção.

O objetivo é simples: qualquer pessoa da equipe Lumtree deve conseguir criar um novo curso seguindo este guia — com consistência de qualidade, identidade visual e experiência de aprendizagem.

Este é um documento vivo. Atualize sempre que uma nova decisão for tomada em produção. A versão mais recente deve estar sempre acessível para toda a equipe.

Os 5 pilares pedagógicos

1. Andragogia aplicada
Adultos aprendem pela prática e pela relevância imediata. Cada conceito vem com ferramenta. Cada ferramenta vem com exercício.
2. Progressão com âncora
O aluno escolhe um projeto real no início e o carrega por todo o curso. No final, tem algo concreto estruturado.
3. Diversidade de estímulos
Vídeo → leitura → glossário → exercício → toolkit → case → output. Nunca o mesmo formato por muito tempo.
4. IA como copiloto
Prompts prontos em cada módulo — não como curiosidade, mas como ferramenta de trabalho real do dia a dia.
5. Output concreto
O curso não termina com uma prova. Termina com algo que o aluno pode mostrar: um toolkit preenchido, uma apresentação, um documento real.

Antes de começar

Decisões que precisam
ser tomadas primeiro

Antes de produzir qualquer conteúdo, defina estas 6 questões. Elas vão guiar todas as outras decisões.

1
Qual é o problema central que o curso resolve?
Escreva em uma frase. Exemplo: "Profissionais que gerenciam projetos sem método formal e perdem eficiência." Se não conseguir escrever em uma frase, o tema ainda não está claro o suficiente.
2
Qual é o output final do aluno?
O que o aluno vai ter nas mãos ao terminar o curso? Deve ser algo concreto — um documento, uma apresentação, um conjunto de ferramentas preenchidas. Defina isso antes de escrever o Módulo 1.
3
Quais são os toolkits do curso?
Cada curso deve ter entre 4 e 6 toolkits interativos. São as ferramentas que o aluno leva. Defina os nomes e a função de cada um antes de começar a produção dos módulos.
4
Qual é o projeto âncora do aluno?
Defina qual tipo de projeto ou situação real o aluno vai usar como base para os exercícios ao longo do curso. Precisa ser algo que qualquer aluno do público-alvo consiga identificar no próprio trabalho.
5
Qual é o modelo de distribuição?
Padrão Lumtree: Módulo 0 + Ementa gratuitos no GitHub Pages como isca. Curso completo pago na Kiwify. Definir o preço individual antes da produção para incluir no material de vendas.
6
Quais são os 4 perfis do diagnóstico?
Todo curso Lumtree tem um diagnóstico de perfil no Módulo 0 com 5 perguntas e 4 perfis de resultado. Os perfis devem fazer sentido para o tema do curso e ser nomeados com estilo de gestão — não com rótulos genéricos.

Conteúdo

Como construir
cada módulo

Cada módulo é um arquivo HTML autossuficiente. Ele abre no navegador sem precisar de nenhuma instalação. A estrutura interna de cada módulo segue sempre o mesmo padrão.

Estrutura interna obrigatória

01
Abertura
Vídeo de abertura (90 segundos)
Contextualiza o que vem no módulo. Cria antecipação. Apresenta o desafio que o aluno vai resolver. Gravado com slides ao fundo, tom próximo e informal.
Vídeo obrigatório
02
Conceitos
Conteúdo teórico aplicado
Teoria mínima necessária — sem abstração gratuita. Exemplos do mundo real. Glossário interativo quando necessário (mínimo 15 termos). Linguagem inclusiva obrigatória.
HTMLGlossário opcional
03
Ferramentas
Ferramentas + Prompts de IA
Apresentação das ferramentas do módulo com contexto de uso. Para cada ferramenta: 1 prompt de IA pronto para usar. Os prompts devem ser testados antes de publicar.
HTMLIA integrada
04
Exercício
Exercício ancorado no projeto real
O aluno aplica o conteúdo no seu próprio projeto — não em caso fictício. Mínimo 3 etapas progressivas. Campo de texto com mínimo de caracteres para habilitar o próximo passo. Dica discreta embaixo do campo.
HTML interativo
05
Output
Entregável concreto
Algo que o aluno leva: toolkit preenchido, documento, template. Deve ser utilizável imediatamente no trabalho. No Módulo 5: apresentação executiva em 5 slides.
Toolkit ou documento
Versão Kiwify vs versão GitHub: Os HTMLs publicados na Kiwify não têm botões de navegação entre módulos — a Kiwify cuida disso pelo menu lateral. Os HTMLs do GitHub (Módulo 0 e Ementa) podem ter navegação própria.
Ferramentas interativas

Como criar
os toolkits

Os toolkits são a principal entrega de valor dos cursos Lumtree. Cada toolkit é um arquivo HTML independente hospedado na pasta assets/ do GitHub.

Padrão obrigatório de todo toolkit

  • ✓
    Duas abas: "O que é [nome]" + "Preencher meu [nome]"
  • ✓
    Header preto com logo Lumtree branca + tag "Toolkit · Módulo X"
  • ✓
    Instruções de preenchimento em 4 colunas no topo da aba de edição
  • ✓
    Matriz/tabela em branco com ponto de partida parcial — editável diretamente no navegador
  • ✓
    Exemplo retrátil — link "Ver exemplo" que abre painel pequeno sem afetar o preenchimento
  • ✓
    Botão deletar linha — visível, com confirmação antes de apagar
  • ✓
    Salvar como HTML — preserva o preenchimento para continuar depois
  • ✓
    Exportar para Excel (CSV) — com BOM UTF-8 para abrir corretamente no Excel
  • ✓
    Imprimir / PDF — header preto com logo branca no impresso
  • ✓
    Toast de confirmação nas ações de salvar e exportar
  • ✓
    Ícones SVG nas cores Lumtree — nunca emojis

Produção audiovisual

Os 6 vídeos
estratégicos

Todo curso Lumtree deve ter 6 vídeos gravados. Eles cobrem os momentos que mais precisam de presença humana — não substituem o conteúdo, complementam.

# Vídeo Onde Duração Função
1 Boas-vindas ao curso Módulo 0 90 seg Apresenta a pessoa instrutora, cria conexão e destaca os diferenciais do curso
2 Abertura Módulo 1 Módulo 1 90 seg Contextualiza o módulo e cria antecipação para o conteúdo
3 Abertura Módulo 2 Módulo 2 90 seg Apresenta as ferramentas que vêm e o impacto prático de cada uma
4 Abertura Módulo 3 Módulo 3 90 seg Apresenta os cases e prepara o aluno para o formato de decisão
5 Case real fictício Módulo 3 3 min Conta uma história de projeto que deu errado e como as ferramentas teriam mudado o resultado
6 Encerramento Módulo 5 90 seg Parabeniza o aluno, reforça o aprendizado e abre para o próximo passo

Padrão de produção

Formato
Pessoa instrutora falando para câmera com slides ao fundo. Celular ou câmera — qualidade boa de áudio é mais importante que vídeo.
Tom
Próximo e informal — como uma conversa. Nunca leitura de teleprompter. A pessoa deve parecer que está falando com uma pessoa só.
Equipamento mínimo
Celular com câmera boa + microfone lapela USB + ring light simples + fundo neutro ou estante com livros.
Edição
CapCut (gratuito). Vinheta Lumtree de 3 seg. Lower thirds com nome e cargo. Textos-chave na tela. Música instrumental baixa.
Módulo 0

O diagnóstico
de perfil

Todo Módulo 0 da Lumtree termina com um diagnóstico de perfil — 5 perguntas que revelam o estilo de gestão ou abordagem da pessoa em relação ao tema do curso.

Estrutura do diagnóstico

5
Perguntas comportamentais — não de conhecimento
As perguntas devem revelar como a pessoa age hoje — não o que ela sabe. Exemplo correto: "Quando um projeto atrasa, sua primeira reação é..." — não: "O que é um milestone?"
3
Alternativas por pergunta
Cada pergunta tem 3 alternativas — A, B ou C. Nenhuma deve parecer obviamente "errada". As três devem ser reconhecíveis como comportamentos reais do público-alvo.
4
Perfis de resultado
4 perfis calculados a partir das respostas. Nomes no padrão Lumtree: "[Adjetivo] + [Substantivo de gestão]". Exemplo: Gestão Estratégica, Gestão Reativa, Gestão Comunicadora, Gestão Equilibrada.
Cada resultado deve ter: nome do perfil, descrição honesta e dica personalizada para aproveitar melhor o curso.
Por que o diagnóstico funciona: Ele transforma o Módulo 0 de uma apresentação em uma experiência. O aluno para de ser espectador e passa a ser participante — antes mesmo de chegar ao conteúdo do Módulo 1.

Publicação

Configurando na
Kiwify

Conta única Lumtree: Todos os cursos ficam na mesma conta Kiwify da Lumtree. Cada curso é um produto separado. Nunca criar contas individuais por curso.

Configuração do produto

1
Criar produto
Produtos → Criar produto → Tipo: Pagamento único · Entrega: Área de membros Kiwify (nunca "externa")
2
Preencher dados do produto
Nome em maiúsculas · Descrição com gancho forte · Categoria: Educação · Capa: 300x250px com identidade Lumtree (fundo preto, elementos coloridos)
3
Criar módulos na Área de Membros
Área de Membros → [nome do curso] → Adicionar módulo. Criar apenas 1 módulo: "CURSO COMPLETO" (os conteúdos gratuitos ficam no GitHub, não na Kiwify)
4
Criar aulas com botão de acesso
Para cada módulo e toolkit: Adicionar conteúdo → preencher título → texto de contextualização no editor → clicar em </> → colar o HTML do botão no final
